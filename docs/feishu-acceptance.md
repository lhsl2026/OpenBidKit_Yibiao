## 本地配置与运行边界

本地 `.env` 已设置用户确认的公司主体、现有台账路径、独立内部密钥和关闭投递模式。已有旧部署中的飞书应用、验签及 handoff/relay 配置已映射到新服务的本地配置，未修改旧部署文件，未输出凭证。模型 API Key/模型名、来源/操作者绑定等仍需补齐并验证。

实现提交 `7f878f0` 已快进合并到本机 `codex/feishu-integration`，合并后再次验证 77/77。当前后台进程仅供本机验证，尚未配置开机启动或监管器自动重启。`data/service.pid` 记录本次进程 ID，`data/service.stdout.log` / `data/service.stderr.log` 保存运行日志。

旧 Docker 引擎探针失败，现有预读栈尚未在本次任务中恢复。可选 Compose 覆盖文件只准备了主机访问端口，没有实际应用。本服务的 `/ready` 返回 503 表示当前接入尚未就绪，不能把本机测试通过描述为每天已自动运行。

没有执行真实收费模型生成、向真实飞书群发卡/发文件、切换正式流量或签章提交标书。仓库中的 HTML 卡片只是清楚标注的离线示意。
