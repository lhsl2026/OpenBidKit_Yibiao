## 本轮补齐的实现

- 雷达历史轮询、分页窗口和持久游标；规范化 text/post 内容跨入口去重。来源消息编辑后保存原文与变更，阻止旧结果、晚到响应和旧卡继续自动判标。
- 飞书群内多选预读；绑定来源批次、实际投递消息、授权员工和随机挑战值。重放返回持久结果，不由助手代替员工选择。接口返回未知结果时保留人工核对状态。
- 贵州官方公开 XML-ZYZF 正文恢复，限制来源、请求次数、下载长度及 ZIP 内容；下载、上传、附加分阶段持久化。上传或附加结果不明时停止自动重做，临时签名 URL 不落库。
- 正文按 SHA-256 绑定至 writing/sources，与 handoff 校验和一致才交给编写流程；已经实际附加的文件先登记，避免重复上传。
- Windows 单实例监管、精确进程身份核验及登录任务安装脚本；健康失效后先结束旧进程再启动替代进程。模型未就绪不触发重启，中断的收费编写不自动重跑。
- 台账附件改为 1 MiB 分块校验，解决整文件读取引发的外部内存压力；测试并发限制为两个 worker。

## 本机部署验收

实现提交 `8a985ed` 已快进合并到本机运行分支，未推送。实际应用私有迁移前备份 SQLite；两任务的原正文和来源收件箱绑定已登记，过期未发送日报已停发。指定测试群三项目选择卡发送成功并回读，员工尚未操作。

`\OpenBidKitFeishu` 登录任务已注册，监管器与主进程实际运行，健康接口 200，雷达轮询成功，专用机器人回调长连接就绪。初次任务使用 Windows PowerShell 5 因其执行策略失败；核对刚创建任务的完整动作后，仅改用当前已配置 RemoteSigned 的 PowerShell 7。未修改执行策略。

台账刷新超过 60 秒的问题已修复：运行时仅读取具备明确归属映射的候选附件，全审计模式保留。真实 Worker 扫描约 3.9 秒，返回全部 1,638 条记录，其中 4 条 verified，其余 1,634 条仍有待核实事项。

## 验收边界与待办

最终完整测试 153/153 通过，0 失败、0 跳过，约 24 秒；显式使用私有 manifest 验证两份真实 ZYZF 正文大小与哈希。CJS、PowerShell 语法及 Git 差异检查通过，独立审查覆盖来源编辑竞态、卡片持久更新和正文阶段接缝。真实 Electron 导出测试使用合成正文，不能作为真实模型生成的证据。客户端生产构建与原生 SQLite 已在上轮通过，本轮没有修改客户端。

剩余业务验收需要可用文本模型配置，以及授权员工一次真实卡片点击。接入模型后，需对原文件执行受控解析重试，完成预读、资格原文核对、员工决策、目录/事实确认和 Word 初稿回传。已经 resolved 的补件动作不能再次提交。

公司资质、人员证书/社保和更多业绩归属仍须逐条核实；规则或证据不足时保持待核实。当前官方文件自动恢复仅覆盖已验证的贵州 XML-ZYZF，其余来源保留人工补件。

登录任务只在当前用户登录且机器运行时工作；注销、关机和休眠期间不能保证接收。全天运行需迁移至常开主机。操作说明见 [飞书联动 README](../integrations/feishu/README.md) 和 [Windows 部署](../integrations/feishu/deployment/README.md)。
