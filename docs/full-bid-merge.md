# 完整标书合并

“完整标书”位于桌面端“标书生成”菜单，用于把当前工作区中已完成的商务标和技术标一次生成成新的 DOCX。合并不会修改两个分册的工作区数据或已导出文件。

## 组卷顺序

1. 封面
2. Word 目录
3. 第一部分 商务标
4. 第二部分 技术标
5. 待补资料与交付前检查

商务标、技术标和交付检查分别起页。目录首次打开即可显示章节名称；在 Word 中更新目录字段后会补齐当前文件页码。

## 合并条件

- 技术标已有目录和正文，且正文生成任务不处于运行、暂停或等待暂停状态。
- 商务标正文生成已完成，且生成任务不处于运行、暂停或等待暂停状态。
- 技术标与商务标都填写项目名称时，名称必须完全一致；仅一侧填写时使用已填写的名称。
- 商务标已选择公司主体。
- 商务标导出前的材料归属、原件哈希及有效期检查仍然执行。

不满足条件时，页面显示具体原因，并提供返回对应分册的入口。导出时会再次执行校验，防止页面打开后工作区发生变化。

## 实现说明

合并在目录数据层完成，由既有 Word 导出服务一次生成文档，不拼接两个已导出的 DOCX。因此图片关系、Markdown 表格、Mermaid 转图、标题样式、页眉页脚和当前模版设置继续使用原导出链路。商务标的待补资料清单从商务卷中移到整本末尾，报价、签字、盖章及最终投标提交仍由人工确认。

聚焦测试覆盖组卷顺序、递归 ID 隔离、项目名称冲突、分册缺失或生成中、输入不可变、导出服务调用、专业封面和可更新目录。样例 DOCX 已使用 Microsoft Word 渲染检查封面、目录、分册起页、表格和待补清单。
