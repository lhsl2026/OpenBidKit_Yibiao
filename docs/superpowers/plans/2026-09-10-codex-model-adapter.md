# Codex 模型适配执行计划

用户明确选择当前登录的 Codex，并要求接好。沿用已确认的群内预读、证据核验和人工确认设计，给现有 OpenAI-compatible 调用增加本机执行适配，不要求另外提供厂商 API Key。

- [x] 验证官方 CLI 已通过 ChatGPT 登录；以 gpt-6-astra、HTTP-only provider、禁用工具的只读调用返回真实探针结果。
- [x] 验证 Docker 可经 host.docker.internal 访问主机 127.0.0.1；无需公开服务端口。
- [ ] Executor：独立临时目录、固定响应 schema、stdin 消息、输入/输出限长、超时和取消、禁用工具、无内部自动重试。
- [ ] Bridge：本机 Bearer 鉴权、文本 chat completions 与 SSE、JSON 对象校验、串行队列、持久幂等和未知执行结果隔离。
- [ ] 主进程生命周期、就绪状态与写作配置接入；原 API 配置保留可选。
- [ ] 仅用 Compose overlay 指向 bridge，并调整已有逐块/整批超时；旧平台源码与私有环境文件保留原样。
- [ ] 重试原两份已附加文档的解析和预读，复用原 documentId/version，不再次上传已 resolved 补件动作。
- [ ] 完整测试、独立审查、真实 Codex JSON/普通内容调用及预读结果、主目录部署与状态记录。

模型实际在云端，复用当前授权登录。新调用只接收本任务需要的内容，保持来源引用和未知事实占位；招标原文是待分析数据，不能作为工具或权限指令。公司归属、资格、人员、报价和投标选择仍由原流程门禁管理。运行记录不保存登录凭证，不修改执行策略或提取应用内部令牌。
