# 联智标公开 GitHub 发布规格

## 目标

把当前联智标桌面端的可公开源码安全推送到 `lhsl2026/OpenBidKit_Yibiao`，并为普通用户提供可直接下载的 GitHub Release 安装包。

## 范围

- 保留并审查当前工作区已有改动，不重置、不覆盖用户文件。
- 修正中英文 README，使下载入口指向本仓库 Releases。
- 忽略本地 `client/release-*` 验收和打包目录，避免误提交大体积二进制产物。
- 对待提交内容执行凭证模式扫描、Git 差异检查、相关测试和客户端生产构建。
- 推送 `main`，创建首个正式版本标签 `v0.1.0`，由现有 GitHub Actions 构建发布产物。

## 安全边界

- 不提交 API Key、Token、私钥、本地 `.env`、数据库、公司私有材料、群/消息收据或本地用户数据。
- `.env.example` 只能包含空值或明显占位值。
- 不生成或轮换现有许可证/构建证明私钥；只在找到与已提交公钥匹配的现有私钥时配置 GitHub Secret。
- 如果缺少现有私钥，源码可以安全推送，但不得创建会必然失败的正式发布标签。

## 验收条件

- `git diff --check` 通过。
- 所有准备提交的新增文件均通过人工路径审查和凭证模式扫描。
- 客户端要求的定向测试、Electron 原生依赖烟测和 `npm run build` 通过。
- 飞书集成改动的测试通过，或明确记录环境性跳过项。
- GitHub `main` 与本地发布提交一致。
- 若签名密钥可用，`v0.1.0` 工作流成功并生成可下载产物；否则明确停在“源码已发布、Release 等待既有私钥”的状态。
